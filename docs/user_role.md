# User Role: 初中英语水平学习者

## 画像

- 词汇量约 1000-1500
- 能读懂简单句，遇到复合句/生词多就放弃
- 听力弱，需要慢速、可重复的发音
- 对国际政治、经济金融话题无兴趣也看不懂
- 喜欢科技趣闻、动物、明星、体育、游戏等话题
- 需要中文兜底才有安全感去阅读英文

## 核心期待

1. **80%以上的词我认识** — 一篇文章只有少数几个生词需要学，满屏高亮直接关掉
2. **一键看到整句中文翻译** — 看不懂的句子要有逃生出口，别让我一个词一个词查
3. **发音慢且可重复** — 朗读速度要能调到很慢，最好能单句循环
4. **内容贴近我的世界** — 科技趣闻、动物、体育、游戏，别给我推国际政治
5. **被鼓励而非打击** — 连续打卡比正确率更应该被表扬

## 什么会让我不爽

1. **AI替换把文章变成天书** — 原文能懂的句子被替换后反而看不懂了
2. **生词太多** — 每篇200词的文章，3-5个生词是上限，8-12个直接放弃
3. **英文释义看不懂** — 单词释义需要中文解释+中文例句，常用搭配
4. **复习节奏不对** — 还没忘就被逼着复习很烦，真忘了又隔太久
5. **没有"我已经会了"的出口** — 学校学过的词系统还反复推，感觉被当傻子
6. **产品界面英文太多** — 设置页、提示、错误信息都英文的话根本操作不了

## 什么会让我受用

1. **"今天我读了真正的英语新闻"的成就感**
2. **看到进步痕迹** — 词的颜色从红变黄再变绿，直观感受成长
3. **发音被温柔纠正** — 不是冷冰冰的"不标准"，而是具体指导
4. **5分钟搞定** — 超短文章，随时随地来一篇，零借口不去做
5. **复习恰到好处** — 快忘的时候刚好出现，不是机械间隔
6. **内容和生活关联** — 刚好学校教被动语态，文章里就有被动语态的句子

## 核心原则

**我要的不是一个"词汇学习系统"，而是一个不会让我觉得自己很笨的英文阅读伴侣。**

安全感（随时有中文兜底）> 效率，鼓励 > 算法，读完 > 学好。
