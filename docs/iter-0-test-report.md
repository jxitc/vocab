## What's Frustrating / Blocking (ranked by severity)

### 致命缺陷 (Critical)

1. **没有任何交互** — 点击单词没有反应，没有翻译弹出，没有词典。整个页面就是一段静态文本。零 JavaScript，零可点击元素。我遇到不认识的词只能干瞪眼。如果我没有词典APP在手边，我就死在这里了。

2. **生词太多了，完全读不下去** — 这篇文章304个词，我数了数，我（初中生词汇量）至少有40-50个词不认识。整篇文章我大概只能看懂50-60%。第一个句子就吓到我了：`groundbreaking`, `effective`, `vocabulary`, `researchers`, `tracked`, `retention`, `traditional`, `flashcard`... 8个生词挤在一个句子里。用户画像里说的是"3-5个生词是上限，8-12个直接放弃"，这里直接翻了4-5倍。

3. **没有中文兜底** — 页面除了标题栏那几个字以外全部是英文。文章没有中文翻译，看不懂就是看不懂，没有逃生出口。用户画像说得清清楚楚："需要中文兜底才有安全感去阅读英文"，"看不懂的句子要有逃生出口"。现在这个页面就是把我扔进了深水区，连个救生圈都没有。

4. **文章内容我不感兴趣** — 一篇关于"语言学习方法论"的学术研究文章？讲的是大学生做实验，脑神经连接，间隔重复算法？我（一个初中生）只想知道新出的游戏有什么好玩的，哪个明星又发新歌了，或者有什么科技趣闻。这篇文章像是给我的英语老师写的，不是给我写的。

### 严重缺陷 (Major)

5. **没有发音** — 遇到不会读的词完全没办法。连个TTS按钮都没有。用户画像说需要"发音慢且可重复"。

6. **没有进度追踪** — 我读完有什么变化？什么都没有。没有"今天已读"，没有打卡，没有词汇统计。读了等于没读，我没有任何成就感。

7. **没有鼓励** — 读完这篇文章是件很累的事情，但页面上没有任何"真棒""完成"之类的反馈。我感觉自己只是在看一篇网页文档，看完就关掉了。用户画像说"被鼓励而非打击，连续打卡比正确率更应该被表扬"。

8. **没有任何分级提示** — 我不知道这篇文章适不适合我。是给小学的？初中的？还是给大学生的？没有人告诉我。我只能自己撞上去，然后发现自己读不懂。

### 一般缺陷 (Minor)

9. **首行缩进的看着不习惯** — 除了第一段，每段都有首行缩进（`text-indent: 2em`），这在英文排版里不太常见，有点怪。

10. **只有一个页面，没有下一篇** — 如果我硬着头皮读完了，接下来点哪里？没有"下一篇文章"按钮，没有导航。

## Critical Gaps (must fix in Iter 1)

按优先级排序：

### 1. 必须加中文翻译（句子级别）
这是最重要的一步。每个段落下面需要中文翻译，或者至少提供"点击显示翻译"的按钮。没有这个，用户根本读不完第一段就会关掉。用户画像的核心原则是："安全感（随时有中文兜底） > 效率"。

### 2. 必须加生词标注 + 点击查词
把超过初中词汇量的词标出来（比如加下划线或背景色），点击后弹出中文释义。这才是"词汇学习"产品最基础的功能。不要求AI替换，先做到标注+查词就行。

### 3. 必须降低文章难度
换一篇简单得多的文章。目标：80%以上的词是初中生认识的。话题换到科技趣闻、动物、游戏或体育。现在这篇文章无论从话题还是词汇角度都不适合初中生。

### 4. 必须加中文界面
所有UI标签和按钮都必须是中文的。现在虽然标签不多，但任何英文提示都会让初中生感到不安。

### 5. 必须加"读完"反馈
至少要有：完成按钮 → 点击后显示"你今天读了一篇英语新闻，真棒！" 让用户有闭合感和成就感。
