# MVP Spec — Vocab in News (v2)

## 目标用户
初中生（12-15岁），英语学习辅助工具

## 核心功能（3页面）

### 1. 阅读页面 `/`
- 每天自动推送一篇文章（按日期固定）
- 自动标注超出初中难度的词（黄色高亮）
- **任意词可点击**查中文释义（不只是高亮词）
- 段落中文翻译（可折叠）
- "我读完了"按钮

### 2. 单词本页面 `/words`
- 展示用户学过的单词列表
- 标记"已学"/"认识"两种状态
- 点击可查看释义

### 3. 测试页面 `/quiz`
- 基于当天文章生词的测验
- 英→中选择题
- T/F阅读理解题
- 完成后显示得分

## 用户系统
- 用户名即可登录（无密码）
- 学习数据按用户存储（服务端）
- localStorage 作为未登录时的临时存储

## 砍掉的功能（v1 保留在 git tag v1-full-feature）
- 4级难度选择器 → 固定初中
- 话题筛选/搜索/排序 → 每天一篇无需选择
- 多文章切换 → 每天一篇
- 收藏文章 → 无多文章
- 成就徽章系统 → MVP后迭代
- 深色模式 → 保持简单亮色
- 专注模式 → 已足够简洁
- 阅读统计/计时器 → MVP后迭代
- 进度条/返回顶部 → 保留或移除
- 段落朗读 → MVP后迭代
- 复习卡片 → 由测试页替代
- 词汇导出/分享 → MVP后迭代
- 键盘快捷键 → 精简
- 文章搜索 → 每天一篇无需
- 随机文章 → 每天一篇无需
